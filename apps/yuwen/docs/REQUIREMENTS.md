# 小小语文家 · 拼音闯关 需求文档

项目代号：kids-yuwen
定位：人教版（部编版）一年级上册「汉语拼音 1-13 课」系统化练习 web 应用
目标用户：5-7 岁幼小衔接 / 一年级孩子 + 家长
形态：移动端优先的 Web 应用（可 PWA 化），平板/手机使用为主

==========================================================
1. 背景与目标
==========================================================

1.1 为什么做这件事
- 拼音是小学语文的第一道关，但学校课堂节奏快、班级人数多，老师很难兼顾每个孩子
- 孩子在 1-13 课期间会反复出现：单韵母/声母/复韵母/整体认读/前鼻后鼻音的混淆；声调标错位置；jqx 与 ü 的拼写规则记错
- 家长辅导成本高：自己发音不一定准、不知道自己孩子错在哪、不知道怎么讲规则
- 配套视频和练习册（家长已收集）覆盖 1-13 课全部知识点，但是被动消费型，孩子缺乏主动练习和即时反馈

1.2 产品目标
- 把"被动看视频/翻练习册"变成"主动练习 + 即时反馈 + 错题巩固"的闭环
- 让孩子像闯关一样完成 13 课学习，每课过关才能解锁下一课
- 给家长一份可量化、可追溯的进度报告
- 教学法上保持真实教学深度：先讲规则（声母/韵母的发音部位、拼读规则、声调规则），再练，再错题重练

1.3 范围与非目标
范围内：拼音 1-13 课的学习与练习、错题本、复习闯关、家长报告
非目标（v1）：
- 识字、看图说话、课文背诵（不是拼音的事）
- 多账号云端同步（v1 本地优先，v2 再考虑）
- 真人 1v1 直播课

==========================================================
2. 目标用户与场景
==========================================================

2.1 主要用户：孩子（5-7 岁）
- 注意力短：单次练习 3-8 分钟一关，不能超 10 分钟
- 不识字或识字少：UI 要配拼音注音 + 语音 + 大图
- 喜欢激励：星星/勋章/连击/解锁下一课/卡通形象反馈
- 不喜欢挫败感：错误时不能直接说"错"，要给鼓励 + 正确示范

2.2 次要用户：家长
- 想知道孩子今天学了什么、错了哪些、会不会反复错
- 想知道孩子跟学校进度差多远（学校现在上到第几课）
- 想要清晰的工具帮自己辅导：发音示范、规则讲解、错题讲解
- 想要护眼/时长控制：单次时长、休息提醒

2.3 典型场景
- 晚饭后 10 分钟：孩子自己点开 APP 完成一关练习
- 周末 30 分钟：家长陪孩子做"复习闯关"和"错题本"
- 家长打开"进度报告"：看本周孩子哪几课最薄弱

3. 教学内容设计
==========================================================

3.1 课程结构（基于人教版部编版一年级上册拼音 1-13 课）

关卡结构遵循"先讲后练"：每个关 = 知识点讲解 → 例题示范 → 闯关练习 → 错题巩固

| 课号 | 主题                          | 核心知识点                                                  | 配套视频 |
|------|-------------------------------|-------------------------------------------------------------|----------|
| L01  | 单韵母 a o e                  | 6 个单韵母、四个声调、标调规则                              | v1       |
| L02  | 单韵母 i u ü + y w           | i u ü、y w 的用法、整体认读 yi wu yu、ü 的标调与省略规则   | v2       |
| L03  | 声母 b p m f                  | 四个声母、两拼音节、三拼音节                                | v3       |
| L04  | 声母 d t n l                  | 四个声母、n l 的区分（边音鼻音）                             | v4       |
| L05  | 声母 g k h                    | 三个声母、相关音节                                          | v5       |
| L06  | 声母 j q x + ü 省略规则       | j q x、ü 上两点的省略规则                                   | v6       |
| L07  | 平舌音 z c s + 整体认读       | z c s、整体认读 zi ci si                                    | v7       |
| L08  | 翘舌音 zh ch sh r + 整体认读  | zh ch sh r、整体认读 zhi chi shi ri                        | v8       |
| L09  | 复韵母 ai ei ui               | 三个复韵母、标调规则（"i u 并列标在后"）                   | v10      |
| L10  | 复韵母 ao ou iu               | 三个复韵母                                                  | v9       |
| L11  | 复韵母 ie üe + 特殊韵母 er    | ie üe er、整体认读 ye yue                                   | v11      |
| L12  | 前鼻韵母 an en in un ün       | 5 个前鼻韵母、鼻音 n 的发音                                 | v12      |
| L13  | 后鼻韵母 ang eng ing ong      | 4 个后鼻韵母、鼻音 ng 的发音、与前鼻音对比                  | v13      |

3.2 每个关卡的内部结构
每个关卡 (Lx) 包含 5 个阶段：

  阶段1 认识（看 + 听）
    - 展示本课 1-3 个新字母/规则
    - 配大图 + 标准发音（真人或 TTS）
    - 让孩子点屏幕跟读 2-3 遍

  阶段2 示范（看视频）
    - 播放家长提供的对应 mp4（v1-v13）
    - 视频即听写示范，孩子先看

  阶段3 听写（写）
    - 屏幕显示「听」按钮
    - 点一下播放一个音节（女声/男声）
    - 孩子在屏幕上的四线三格用手指/鼠标手写
    - 写完一个单元（一组 5-8 个音节）后提交
    - 提交后逐个对比，错的进入错题本

  阶段4 拼读（选）
    - 给汉字 + 拼音选项（4 选 1 或 2 选 1）
    - 或给拼音 + 选汉字（配图）
    - 答对有即时反馈（"棒！b + a = ba，爸妈的爸"）

  阶段5 综合（闯关）
    - 混合题型（听写 + 拼读 + 标调 + 找错）
    - 8-12 题，限时（无倒计时，给鼓励）
    - 8/10 正确即过关，未达标的错题全部进错题本

3.3 复习体系
- 错题本：自动收集错题，按课归类，按艾宾浩斯曲线推送重练（1天后、3天后、7天后）
- 复习闯关：每 3 课解锁一个"综合复习关"，覆盖已学课
- 拼音总动员：13 课全学完后解锁的全册综合挑战

4. 核心功能模块
==========================================================

4.1 课程学习（孩子主流程）
- 课程地图：13 课卡片 + 复习关 + 总动员
- 每课：认识 → 示范 → 听写 → 拼读 → 闯关
- 解锁机制：闯关通过 ≥ 8/10 才能解锁下一课
- 进度展示：每课卡片显示"已学/总关数"、"星星数"、"错题数"
- 隐藏解锁（开发用）：URL 加 ?unlock=all 或连续点击标题 5 次，解锁全部关卡

4.2 听写训练
- 四线三格手写输入（触屏手指 + 鼠标拖动两种方式）
- 播放控制：单字/单音节/整组（"下一个"/"再听一遍"/"整组连播"）
- 音节库：每课预设 30-50 个音节（声母+韵母+声调组合）
- 随机抽题：每次进关从该课音节库随机抽 8-10 个
- 答案比对：笔画 + 位置 + 拼音三者比对（先做拼音比对，笔画比对 v2 再做）
- 错题回放：错题可以"再听一遍正确读音"和"看正确写法"

4.3 拼读练习（基于 PDF 44 页配套练习题题型归纳）

按出现频次排序的核心题型（PDF 实际考察过的）：

  题型 A：拼音描红/抄写
    - 在屏幕四线三格里临摹抄写声母/韵母/音节
    - 配合手写组件，孩子跟着示范写

  题型 B：看图写拼音
    - 配图（公鸡/气球/西瓜/妈妈/马路...）→ 写出对应声母/韵母/音节
    - 这是 PDF 最高频的"看图"题型，必须重点支持

  题型 C：拼一拼，写一写
    - 给中心声母 + 四周单韵母（m/a、i/u、o/ü 等）→ 拼读后写出音节
    - 锻炼拼读 + 声调组合能力

  题型 D：音节拆分
    - 给完整音节 → 拆出声母、韵母、声调
    - 例：bǎ → b + a + 三声

  题型 E：标声调
    - 给无调音节 + 声调格 → 在四线三格正确位置标调
    - 标调规则（"i u 并列标在后"、ü 标调等）

  题型 F：辨析圈选
    - 一组音节里圈出三拼音节 / 平舌音 / 翘舌音 / 错误音节
    - 考察辨音能力

  题型 G：图文/音节连线
    - 象形图 + 声母卡片
    - 图 + 音节
    - 字 + 拼音

  题型 H：给汉字 + 选拼音（看字选拼音）
    - 4 选 1 或 2 选 1

  题型 I：给拼音 + 选汉字（看拼音选字 + 配图）
    - 4 选 1

  题型 J：补全音节
    - ___ ǎ → 给出 b/m/d 选 1；或 ɡ ___ → 给出 ō/é 选 1
    - 配套 j q x ü 省略规则专项

  题型 K：按声调分类/统计
    - 把一组音节按一声/二声/三声/四声分类
    - 数每个声调有几个

  题型 L：声母/韵母表默写
    - 按顺序默写全部已学声母/韵母
    - 用于阶段综合关

  题型 M：判断对错
    - 给音节/拼音 → 对/错

  阶段3-4 混用上述题型；阶段5 闯关从每课随机抽 8-12 题覆盖至少 4 种题型。

4.4 错题本
- 自动收集：所有错题（听写错、拼读错、标调错）
- 按课归类：L1-L13 + 复习
- 推送重练：1 天后、3 天后、7 天后自动出现在首页
- 错题重做：完全答对（连续 3 次）才从错题本移除
- 错题讲解：错题点击后展示"正确写法 + 发音 + 规则提示"

4.5 复习闯关
- 阶段性：每 3 课一个综合复习关（R1, R2, R3, R4）
- 综合关题型：覆盖前几课所有知识点
- 总动员：13 课后解锁的全册挑战

4.6 家长端
- 进入方式：首页长按 logo 3 秒或设置页切到"家长模式"
- 进度报告：
  - 本周/本月每课学习时长、练习次数、正确率
  - 错题分布（按知识点归类：声调/标调/省略规则/前后鼻音等）
  - 学习曲线（折线图）
- 设置：
  - 每日时长上限（默认 30 分钟）
  - 强制休息提醒（每 10 分钟）
  - 发音速度（慢/正常/快）
  - 字号/UI 主题
  - 重置进度（带二次确认）
- 辅导工具：
  - 单个字母的标准发音
  - 规则讲解卡（可保存到收藏）
  - 错题本导出（家长可以打印让孩子线下再练）

4.7 激励与游戏化
- 星星：每关通过给 1-3 颗星（3 星 = 满分）
- 勋章：
  - "拼音小达人"（完成第 1 课）
  - "声母全通关"（L3-L8 全过）
  - "复韵母小专家"（L9-L11 全过）
  - "鼻音挑战者"（L12-L13 全过）
  - "错题克星"（错题本清空）
  - "连击王"（连续 7 天练习）
  - "拼音小状元"（总动员通关）
  - "复习小达人"（所有复习关满分）
- 连续打卡：每日首次打开 +1 天，断签 0
- 进度可视：每课一颗小星星，过关后变金色

5. 技术架构
==========================================================

5.1 技术栈（沿用 kids-music-app 同款）
- 构建：Vite 5
- 框架：React 18 + TypeScript
- 样式：Tailwind CSS 3
- 状态：Zustand（轻量、TypeScript 友好）
- 持久化：Dexie（IndexedDB 包装，存错题、进度、设置）
- 路由：React Router 6
- 测试：Vitest + React Testing Library
- 音频：HTML5 Audio + Web Audio API（听写播放）
- 视频：原生 <video> 标签（家长提供的 13 个 mp4）
- 字体：思源黑体 + 配套拼音字体（如方正拼音体或 PinyinKit）

5.4 关键模块设计
- 四线三格手写：触屏 + 鼠标兼容，笔画粗细可调，写完可清除
- 拼音 TTS：v1 用 Web Speech API（SpeechSynthesisUtterance，zh-CN），v2 可接云端真人发音
- 答案比对：拼音文本比对（去声调/带声调两种模式）
- 错题推送：艾宾浩斯（1/3/7 天）由 nextReviewAt 字段驱动
- 家长模式：本地 4 位 PIN 锁，二次确认进入

5.5 性能与离线
- v1 不做 PWA / 离线（v2 评估）
- 视频走本地 public/videos，首屏不预加载，按需加载
- 音节库、题库全部内联代码，无网络依赖

6. 交互与体验
==========================================================

6.1 视觉风格
- 主色：暖橙 + 嫩绿（孩子友好，不刺眼）
- 字号：默认 22px（比 music app 更大，孩子用）
- 按钮：圆角 1rem 起步，最小触控区 64×64
- 动效：过关时的星星飞入、勋章弹出、新课解锁的彩带

6.2 反馈原则
- 答对：星星 + 鼓励语 + 正确发音回放
- 答错：温和提示（"再想想"），不直接说错；点查看答案后才显示正确写法
- 完成：星星动画 + 下一步按钮 + 进度条前进
- 成就：勋章弹窗 + 音效 + 提示家长

6.3 家长视角下的孩子视角
- 孩子模式：全屏、大字、无干扰、卡通头像
- 家长模式：数据密集、表格 + 图表、可导出
- 通过 PIN 切换（默认 0000，首次进入强制改）

6.4 难度与时长控制
- 单关 3-8 分钟，闯关不超过 10 分钟
- 答错 3 次同一题：自动降级给提示（首字母/声调提示）
- 单次连续学习 20 分钟：休息提示（不强制）
- 达到每日上限：提示"今天学得够多了，明天见"

10. 风险与开放问题
==========================================================

已知风险：
- 拼音 TTS 质量：Web Speech API 在不同浏览器/系统发音差异较大，v1 可能不够标准
- 手写识别：v1 仅做拼音文本比对，不做笔画识别；四线三格手写更多是"陪伴感"
- 视频版权：家长提供的视频仅自用，公开版本需替换或自制
- 内容校对：500 音节 + 300 题需要专业老师把关

待用户确认：
- 项目名：暂定「小小语文家 · 拼音闯关」，可改
- v1 是否要做 PWA / 离线？
- 是否要支持多孩子账号（v1 默认单孩子）？
- 是否需要家长用手机号注册（v1 不做，仅本地 PIN）？
