# 02 · 双轨唱名系统 · 简谱与五线谱教学策略

## 为什么双轨

孩子的现实情况：
- 学小提琴 → 用**固定调**（C 就是 C，D 就是 D）
- 学校小歌手 → 用**简谱数字**（跟着老师定调，实际上是首调思维）
- 视唱练耳/音基考级 → 用**首调 solfège**（do 随主音移动）

强行统一到一种系统会打架。方案是明确切分场景。

## 双轨规则

| 场景 | 使用系统 | 举例 |
|---|---|---|
| 视奏五线谱、看谱演奏 | **固定调音名** | 看到线间是 A，就唱/念 A |
| 简谱视唱（小歌手场景） | **简谱数字** | 1=do 2=re 3=mi，跟老师定的调 |
| 听觉训练（听音辨音、旋律听写） | **首调 solfège** | 无论什么调，主音都是 do，用 do-re-mi-sol-la 训练关系听觉 |
| 节奏训练 | **Kodály 读法**（ta / ti-ti / ti-ri 等） | 与音高系统解耦 |

## 界面显示约定

- 五线谱题：右下角标注 `固定调` 灰色小字
- 简谱题：右下角标注 `简谱 · 首调` 小字，明确说"这里的 1 是本首歌的 do"
- 听觉训练题：右下角标注 `耳朵专项 · 首调`，音频不显示谱面，只显示唱名球或色块

## 简谱教学要点（小歌手必需）

1. **数字 = 唱名对应**：1=do 2=re 3=mi 4=fa 5=sol 6=la 7=si
2. **高低点标记**：`1̇` 高音 do、`1̣` 低音 do、`i` 高音简写
3. **时值符号**：
   - 无横线 = 四分（ta）
   - 下加一横 = 八分（ti）
   - 下加两横 = 十六分（ti-ri）
   - 点 = 延长半拍（附点）
   - `-` = 延长一拍（二分为 `1-`，全音符 `1---`）
   - `0` = 休止
4. **调号说明**：`1=C` 意思是这首歌的 do 唱 C 音；`1=G` 就是 do 唱 G

## 五线谱教学要点（小提琴衔接）

由于孩子五线谱识读已熟练，S1 部分只做速通复习：
- 高音谱表五线四间的音名（EGBDF / FACE）
- 加线（上加一线 A，下加一线 C 中央 C）
- 常见节奏在五线谱上的写法
- **重点**：把五线谱和简谱同一乐句并排显示，帮孩子建立映射

## Curwen 手势系统（Kodály 核心组件）

> Curwen 手势是 Kodály 教学法中音高教学的标志性载体。
> 通过空间位置 + 手形变化，让孩子"看见"音高关系、"摸到"音程距离。
> 本产品在所有首调 solfège 场景（耳训、视唱模唱）中同步使用手势。

### 七音手势表

| 唱名 | 手形描述 | 空间位置 | 视觉特征 |
|---|---|---|---|
| do | 握拳，掌心朝下 | 腰部 | 像握住一个球，稳定感 |
| re | 手掌微斜，指尖朝上偏外 | 腰胸之间 | 像小鸟微微起飞 |
| mi | 平掌，掌心朝下，水平 | 胸部 | 最"平"的手势，像桌面 |
| fa | 竖掌，拇指向下指 | 胸肩之间 | 拇指朝地，像"不赞成" |
| sol | 平掌立起，掌心朝向自己，掌侧朝上 | 肩部 | 像挡阳光 |
| la | 手掌微弯呈杯形，掌心朝下 | 肩头之上 | 像撑伞、像"过来" |
| si/ti | 食指竖直上指，其余指收拢 | 头部 | 指向天花板，有"向上找 do"的引导感 |
| do'(高) | 握拳，掌心朝下 | 额头 | 与低 do 同形但高位，形成八度闭环 |

### 教学要点

1. **五声先行**：S1 阶段只练 do-re-mi-sol-la 五个手势，fa 和 si 在 S2 L09 引入
2. **半音手势的"棱角感"**：mi -> fa 手掌从平到竖、拇指突然朝下，身体能感受到"卡了一下"；si -> do' 手指从竖指到握拳收拢，有"找到家"的感觉。这两个转换是 Kodály 让孩子内化半音关系的核心手法
3. **手势与音高方向一致**：手势位置从低到高对应音从低到高，孩子看着老师的手势就能预判音高走向
4. **双手可选**：单手即可，低龄孩子可用非惯用手，不影响

### 产品实现

- **知识讲解段**：动画角色做手势示范，孩子跟着模仿
- **模唱段**：屏幕显示手势动画的同时播放对应音高，孩子边看手势边唱
- **耳训段**：播放音高时不显示谱面，但显示手势动画作为视觉锚点（配合唱名球）
- **手势参考层**：常驻一个可折叠的手势速查卡，孩子卡住时点开看全部 7 个手势

### 手势与唱名球的关系

耳朵专项用的是"唱名球"（色块），课堂模唱段用的是 Curwen 手势。两者不冲突：
- 唱名球 = 纯听觉训练时的视觉提示（不涉及身体动作）
- 手势 = 模唱/视唱时的身体参与（用身体感受音高关系）
- 规则：耳训只出唱名球不出手势；课堂模唱只出手势不出唱名球，保持场景清晰
