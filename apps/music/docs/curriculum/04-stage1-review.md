# 04 · S1 启蒙复习闯关（3 关合并版）

> 原本 16 课的 S1 内容，对你孩子来说太简单了。
> 压缩成 **3 个 5 分钟的复习关卡**，通关即可跳过；不通关则回炉这一模块。

## R1 · 节奏复习关（5 min）

**通关目标**：ta / ti-ti / 四分休止 / 二分 / 全音符 5 种时值听辨准确率 ≥ 80%

题型序列（10 题）：
1. 听 `ta ta ta ta`，选正确节奏卡（3 选 1）
2. 听 `ti-ti ti-ti ta ta`，选正确节奏卡
3. 听 `ta 休 ta 休`，选正确节奏卡（**休止不出声**，靠时长判断）
4. 听 `ta-a ta ta`（含二分音符），选正确节奏卡
5. 听 `ta-a-a-a`（全音符 4 拍），选正确节奏卡
6. 看节奏卡 `ta ti-ti ta`，跟拍（4 拍点击 4 次）
7. 看节奏卡 `ti-ti ta 休 ta`，跟拍（**休止位不拍**）
8. 看节奏卡 `ta ta-a ta`（含二分），跟拍（3 次点击）
9. 听两段节奏，选相同的那一个
10. 综合识别：听后写出 4 拍节奏是什么组合

## R2 · 音高复习关（5 min）

**通关目标**：do-re-mi-sol-la 五个音听辨 + 高低方向判断准确率 ≥ 80%

题型序列（8 题）：
1. 听 do，从 do/re/mi 三选一
2. 听 sol，从 do/mi/sol 三选一
3. 听 la，从 sol/la/do 三选一
4. 听 do → mi，选"上楼 / 下楼 / 原地"
5. 听 sol → mi，选"上楼 / 下楼 / 原地"
6. 听 la → la，选"上楼 / 下楼 / 原地"
7. 听 do-mi-sol（琶音），从三种琶音谱面选正确的
8. 听 sol-mi-do，从三种琶音谱面选正确的

## R3 · 谱面复习关（5 min）

**通关目标**：五线谱识音 + 简谱识音准确率 ≥ 80%

题型序列（10 题）：
1. 五线谱：高音谱表第二线是什么？（G）
2. 五线谱：第三间是什么？（C）
3. 五线谱：下加一线中央 C
4. 简谱：`1 2 3` 读什么（do re mi）
5. 简谱：`1̇` 是什么（高音 do）
6. 简谱：`5.` 附点五 = ？（1.5 拍的 sol）
7. 简谱五线谱对照：给一段简谱 `1 2 3 5`，选对应的五线谱（3 选 1）
8. 简谱五线谱对照：给一段五线谱 CDEG，选对应的简谱
9. 拍号识别：4/4 有几拍
10. 拍号识别：3/4 强弱规律

## 通关判定与跳级

- **三关全过**：直接跳到 S2 L05（正课起点，前八后十六）
- **通过 R1 R2 挂 R3**：进 S2 L01–L04 快过（1 天/课）
- **R1 R2 有任一挂**：从 S1 完整版开始（未来 P2 版本再做，本次 P1 不做）
- **未测评的孩子首次进入**：先跑三关，再决定路径
