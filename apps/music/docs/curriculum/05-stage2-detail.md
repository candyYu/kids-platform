# 05 · S2 初级完整课时表（正课起点）

## S2 阶段总目标

学完 S2 的孩子应能：
1. 熟练读写完整音阶 C 大调、G 大调、F 大调、a 小调
2. 掌握附点、切分、前八后十六、前十六后八四种复杂节奏
3. 能视唱 4 小节内的短句（简谱 + 五线谱双谱）
4. 能听写 2 小节节奏、4 小节 C 大调旋律
5. 能听辨大三和弦 vs 小三和弦

## 每课统一 6 段式结构

1. **暖场**（30s）：一句话说今天学什么
2. **知识讲解**（1–2 min）：动画 + 语音，配双谱示例（五线 + 简谱）
3. **听辨**（2–3 min）：3–5 题
4. **视奏 / 视唱**（2–3 min）：简谱 + 五线谱双轨切换
5. **模唱录音**（1–2 min）：老师示范 → 孩子唱 → 回放
6. **家长小结**（自动）：今天练了什么、正确率、建议
