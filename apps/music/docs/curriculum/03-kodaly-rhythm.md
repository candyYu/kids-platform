# 03 · 正统 Kodály 节奏读法

> 之前草案里的 `tika-tika` / `shh` 是美式变体和国内简化版，**不是正统 Kodály**。
> 本产品采用匈牙利传统的标准读法。

## 标准读法表

| 音符 | 图示 | Kodály 读法 | 拍数 | 备注 |
|---|---|---|---|---|
| 全音符 | 𝅝 | **ta-a-a-a** | 4 拍 | 拖满 4 拍 |
| 二分音符 | 𝅗𝅥 | **ta-a** | 2 拍 | 拖 2 拍 |
| 附点二分 | 𝅗𝅥. | **ta-a-a** | 3 拍 | — |
| 四分音符 | ♩ | **ta** | 1 拍 | 基本单位 |
| 两个八分 | ♫ | **ti-ti** | 各 ½ | — |
| 附点四分+八分 | ♩. ♪ | **ta-i · ti** | 1.5 + 0.5 | 附点节奏 |
| **前八后十六** | ♪ 𝅘𝅥𝅯𝅘𝅥𝅯 | **ti · ti-ri** | 0.5 + 0.25×2 | 孩子正在学 |
| **前十六后八** | 𝅘𝅥𝅯𝅘𝅥𝅯 ♪ | **ti-ri · ti** | 0.25×2 + 0.5 | 孩子正在学 |
| 四个十六分 | 𝅘𝅥𝅯𝅘𝅥𝅯𝅘𝅥𝅯𝅘𝅥𝅯 | **ti-ri-ti-ri** | 各 ¼ | ⚠ 不是 tika-tika |
| 切分节奏 | ♪♩♪ | **ti · ta · ti** | 0.5+1+0.5 | 中间四分为切分点 |
| 三连音（八分） | ♪♪♪ (3连) | **tri-o-la** 或 **ta-ki-da** | 一拍三个 | Takadimi 系统词，Kodály 借用 |

## 休止符处理（**严格 A 方案**）

按你的决定：**休止不发声，只做手势 + 内心默数**。

| 休止 | 处理 |
|---|---|
| 四分休止 𝄽 | 张开手掌向下切 · 内心数"1" · **不出声** |
| 八分休止 𝄾 | 快速小切手 · 内心数"半拍" · **不出声** |
| 二分休止 𝄼 | 双手张开保持 2 拍 · **不出声** |
| 全休止 𝄻 | 双手张开保持 4 拍 · **不出声** |

产品实现：
- 音频层：休止位置真的**留白无声**
- 视觉层：节奏卡上的休止符位置显示一个**手势图标**（张开的手），并有轻微脉冲动画提示"这里要数拍"
- 反馈层：如果孩子跟拍时在休止位置也拍了，反馈"这里是安静的休止，我们数拍但不出声"

## 前八后十六 vs 前十六后八 · 教学关键

这是孩子当前正在学的重点，产品要重点服务：

```
前八后十六 ♪ 𝅘𝅥𝅯 𝅘𝅥𝅯     读：ti      ti-ri
时间轴：   ├──0.5──┤├0.25┤├0.25┤

前十六后八 𝅘𝅥𝅯 𝅘𝅥𝅯 ♪     读：ti-ri     ti
时间轴：   ├0.25┤├0.25┤├──0.5──┤
```

对比训练法（产品题型）：
1. **听辨题**：播放其中一种，孩子选择是"前八后十六"还是"前十六后八"
2. **口读题**：显示图形，孩子跟读 `ti · ti-ri` 或 `ti-ri · ti`
3. **拍击题**：显示图形，孩子按正确时值点击（严格判定节拍点）
4. **对比录音题**：孩子先听两种示范，选出哪一种匹配当前节奏卡

## 体态律动（Dalcroze 元素 · 必须融入节奏教学）

> 纯屏幕交互（听+点）不足以让 6–8 岁孩子内化节奏。
> Kodály 和 Dalcroze 都强调：节奏必须先进入身体，再进入符号。
> 本产品在知识讲解段和部分练习题中嵌入身体参与环节。

### 三层体态活动

| 层级 | 动作 | 用途 | 出现场景 |
|---|---|---|---|
| 大肢体 | 走步、踏步 | 感受稳定拍（每步一拍） | L05 知识讲解段：站起来跟老师走 4 步 |
| 中肢体 | 拍腿、拍手 | 区分拍值（拍腿=ta，拍手=ti-ti） | L05 知识讲解段：前八后十六先拆成"拍腿-拍手拍手" |
| 小肢体 | 指点、手指敲 | 精确到十六分细分 | L05 练习段：屏幕点击对应十六分位置 |

### 前八后十六的体态拆解（L05 教学法）

这是 L05 样板课必须用的教学序列：

```
第一步：走步感受（大肢体）
  老师："我们走 4 步" -> 孩子跟着走 ta-ta-ta-ta
  （建立"一拍"的身体感）

第二步：加速走步
  老师："现在每步变成两个小碎步" -> 孩子走 ti-ti ti-ti ti-ti ti-ti
  （建立"半拍"的身体感）

第三步：混合一步+碎步
  老师："一步走，然后两步碎步" -> 孩子：大步 + 碎碎
  读出来：ti  ti-ri
  这就是前八后十六！

第四步：回到座位，用手拍
  拍腿（长）+ 拍手拍手（快快）= ti ti-ri

第五步：屏幕练习
  看节奏卡，按正确时值点击
```

### 产品实现约束

- 体态环节用语音引导 + 简单动画（角色做动作），不需要摄像头识别
- 每个体态环节不超过 30 秒，避免拖慢节奏
- 不做动作判定（不判断孩子是否真的在走步），只做引导
- 家长端提示"这个环节请确保孩子有站立空间"
