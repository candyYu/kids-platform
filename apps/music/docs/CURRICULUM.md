## 核心决策记录

1. **主线**：视唱练耳 + 乐理（暂不做声乐主线）
2. **分层**：四阶段 S1 → S4，能力优先年龄参考
3. **P1 落地**：S1 复习 3 关 + S2 L05 前八后十六样板课 + 耳朵专项 E1 E4
4. **唱名系统**：双轨制 — 视奏固定调 + 简谱数字，听觉训练首调 solfège
5. **节奏读法**：**正统 Kodály**（ti-ri-ti-ri，不是 tika-tika；休止不发声只手势）
6. **UP 主视频**：仅作教研参考和课后延伸外链，不嵌入教学流程
